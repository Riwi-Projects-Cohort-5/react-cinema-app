# 10 — Iconografía

## Librería recomendada

**Phosphor Icons** (variante _Regular_ como base, _Bold_ para estados activos/seleccionados).

## Estilo

Lineal, geométrico y de esquinas suavemente redondeadas, coherente con el border radius del sistema ([06 — Border Radius](./06-border-radius.md)) y con el carácter técnico-editorial de la tipografía elegida.

## Grosor

- **Regular (1.5px de trazo aparente):** uso general, estado por defecto.
- **Bold:** exclusivamente para íconos en estado activo/seleccionado o dentro de elementos ya destacados (botones primarios), nunca combinado con Regular en un mismo contexto.

## Tamaños

| Token     | Valor | Uso                                                     |
| --------- | ----- | ------------------------------------------------------- |
| `icon-sm` | 16px  | Íconos inline con texto (Caption/Body)                  |
| `icon-md` | 20px  | Íconos en botones, inputs, navegación                   |
| `icon-lg` | 24px  | Íconos destacados, encabezados de sección               |
| `icon-xl` | 32px  | Íconos ilustrativos en estados vacíos o de confirmación |

## Consistencia

Todos los íconos deben provenir de la misma librería y variante de grosor dentro de un mismo contexto visual. No se permite mezclar librerías de íconos bajo ninguna circunstancia, para preservar coherencia formal en todo el producto.
