# Task 3: Edge Case and Fallback Evidence

## Tested Edge Cases & Fallbacks
1. **Loading State (Skeleton)**:
   - When `isPending=true`, displays loading shimmer skeleton matching viewport geometry (`w-full h-[520px] md:h-[430px] min-h-[600px] md:min-h-0`) without `rounded-[1.25rem]`.
2. **Error State**:
   - When `isError=true`, displays error message "No pudimos cargar las películas" and functional "Reintentar" button that triggers `refetch()`.
3. **Empty Data Fallback**:
   - When `movies` is empty array `[]` or null, renders empty state "No hay películas disponibles" without crashing or visual glitch.
4. **Active Backdrop URL Resolution**:
   - Handles TMDB poster URLs converting `/t/p/w500/` to `/t/p/w1280/` backdrop images correctly via `getBackdropUrl`.
5. **No Visual Overflow**:
   - Both root `<section>` and inner `#hero-carousel` contain `overflow-hidden` and `w-full`, preventing horizontal page scrolling.
6. **No Extraneous Image Overlays**:
   - Verified active slide contains no floating corner `<img>` tag and no duplicate poster overlay.
